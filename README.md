# **Test project using two languages ​​simultaneously 💻

**The project is designed to explore integrating two languages ​​into a single project simultaneously.**
---

## 🛠️ Features & Functionality

**The application can track changes in the price of a product on the marketplace, create a price change chart, and enter this data into an Excel spreadsheet.** 
---

## 💻 Tech Stack

* **Frontend Layout: ** С++, Qt framework. 
* **Backend Layout: ** Python.
---

## 🔧 Local Setup & Installation
To use the application, download the folder "marketplaceUI" and launch "marketplaceUI.exe" 
To change the marketplace service implementation, you need to modify "main.py" by replacing the random module with access to the specific marketplace's database.
